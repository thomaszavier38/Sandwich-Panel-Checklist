SANDWICH PANEL INSPECTION CHECKLIST - offline app

This is a self-contained web app. It does not use Claude, any account or any server once installed.
All visits, photos and signatures are stored on the tablet only. PDFs are made on the tablet.

INSTALL (one time, needs internet once)
1. Put this whole folder on any web host (free options: Netlify Drop at app.netlify.com/drop, GitHub Pages, Cloudflare Pages).
   Drag the folder in; you get an https link.
2. Open that link on the tablet.
   iPad (Safari): Share > Add to Home Screen.
   Android (Chrome): menu > Install app / Add to Home screen.
3. Open the app once from the home screen while online. After that it works with no signal.

SAVING PDFs
Android / browser: the PDF goes to the Downloads folder.
iPad: a share sheet opens. Choose "Save to Files" > "On My iPad".

NOTES
- Keep using the same tablet and the same home-screen icon. Data lives in that app only.
- Do not clear the browser's site data, or visits will be deleted. Save PDFs as your permanent copy.
- To update the app later, upload the new folder to the same host and open the app online once.
